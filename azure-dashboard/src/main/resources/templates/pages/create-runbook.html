Runbook Best Practices
  • Always use param() blocks for configurable inputs.
  • Include Write-Output for job logging visibility.
  • Use try/catch for error handling and exit codes.
  • Test with small resource sets before running against production.
  • Use Managed Identity instead of stored credentials.
  • Tag resources before bulk operations for safe targeting.
